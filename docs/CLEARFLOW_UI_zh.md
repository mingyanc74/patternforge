# Clearflow 高保真界面落地

参考用户提供的 Clearflow 历史记录交互 HTML，重做真实应用前端，不修改该参考文件。

## 已映射的设计

- 白色顶栏、Office 蓝色、浅灰侧栏、Segoe UI 字体，无外部字体下载依赖。
- Prepare data / Jobs / Connections 导航；窄屏改为顶部导航。
- Connect → Select file → Configure → Processing → Results 五步流程。
- 历史表格、搜索、状态筛选、5 条一页、创建时间、耗时、查看和复用。
- 数据预览与右侧转换配置、三种操作、明确的“删除匹配内容”选项。
- 提交前复核、取消确认、复用覆盖草稿确认、断开连接确认。
- 处理、失败、重试、取消、成功、结果过期、空记录及无搜索结果状态。
- 键盘焦点、Escape 关闭、弹窗焦点圈定、减少动画和手机布局。

## 真实系统的必要差异

1. 正常页面不植入示例任务。历史来自 Django，按当前会话隔离；服务器过滤和分页，避免只搜索最近 50 条。
2. 复用生成新草稿，不复用旧 inspection ID；必须重新读取源文件并核对列。过期连接需重输凭证，不恢复旧密钥。
3. Original preview 是有明确上限的源数据预览。Spark 可能重排行，不伪造逐行差异；蓝色列仅表示处理目标列。
4. 大文件结果使用签名游标翻页，不伪造可任意跳到的页码或固定三页。
5. 缺少后台服务或模型配置时明确提示，不模拟真实处理成功。
6. 界面显示 Clearflow；仓库名、Python 服务与既有部署配置保留 patternforge。
