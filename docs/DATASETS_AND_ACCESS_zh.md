# 网站门禁、浏览器工作区和 S3 连接

这是三种不同机制，不是同一个“账号登录”。

| 机制 | 用途 | 生命周期 |
|---|---|---|
| 网站访问密码 | 进入演示应用；不是个人注册登录系统或 AWS 登录 | 管理员可配置哈希；更换密码后旧门禁授权失效；Lock workspace 重新锁定当前浏览器 |
| 浏览器 Session | 隔离当前浏览器的连接、导入数据集和任务 | 服务端会话，安全 HttpOnly Cookie；共享门禁密码不共享数据 |
| S3 Connection | 以用户输入的 AWS 凭据检查权限、列举和导入云端文件 | 新连接默认 1 小时；临时 AWS 凭据也可能更早失效 |
| 已导入数据集 | 后台下载并持久保存的只读源文件快照，随后交给 Spark | 默认 24 小时，独立于 S3 连接；页面显示到期时间 |
| 处理结果 | 某个任务生成的分页 Parquet 结果 | 默认 24 小时，独立于源文件和连接 |

## 正常流程

1. 输入网站访问密码。它只解锁应用入口，不会授权访问任何 AWS 资源。
2. 在 Connections 输入自己的 AWS Access Key、Secret、Bucket、Region；临时凭据额外输入 Session Token。
3. 后端真实调用 S3 检查权限并列举对象，CSV/Excel 的“Preview selected file”会提交异步导入任务。
4. Celery 按固定对象版本或 ETag 下载真实字节，检查大小及源一致性，并计算 SHA-256。Spark 从共享数据卷读取快照，解析并生成预览。未完成或失败的导入不会成为可用数据集。
5. 成功导入后可在 Imported datasets 重新打开。即使原连接过期、断开或凭据被清理，仍可在数据集保留期内提交新的处理任务，不再向 AWS 请求源文件。
6. 要浏览或导入新文件，必须重新连接。已经在应用中导入的是一个固定时点的快照，不会自动同步 S3 后续修改。

Excel 有多工作表时，先选择工作表并成功预览，该工作表才成为可处理的数据集。较早版本没有保存快照的旧预览不能追溯变成数据集，需要重新导入。现有任务历史和已生成的结果不会因此删除。

## 实现与安全边界

- 复用成功检查任务的 ID 作为数据集 ID，使用独立的 dataset_path/到期字段和 transform.input_dataset 外键；API 不暴露本机文件路径或原始 AWS 凭据。
- 所有下载、解析、模型推理和数据转换都在后台执行；API 立即返回 Job ID。
- 真实 S3 入口不接受内置样本代替凭据。原有可选模拟桶继续明确标识为 sample，只是单独的开发/演示工具。
- 目录隔离、Session 所有权、CSRF、门禁、取消与租约检查仍执行。快照过期清理会等待引用它的活动任务结束，不在处理中删除输入。
- 原 S3 文件不会被改写。数据集和结果不是无限保存；连接过期与数据过期是两个不同提示。
- 下载到共享卷再交给 Spark 是有意的架构取舍：消耗额外磁盘和一次导入传输，但隔离 AWS 凭据生命周期，使导入后的处理可重复。Spark 多个执行器仍读取共享快照并分区处理；不是浏览器本地处理。

## 配置和 API

`CREDENTIAL_TTL_HOURS=1`、`DATASET_TTL_HOURS=24`；既有连接不会被追溯缩短，新的连接使用新默认值。

网站门禁使用 `DEMO_ACCESS_PASSWORD_HASH_B64`，它是 Django PBKDF2 哈希的 Base64，不是密码的 Base64。密码不存入 Git 或服务器明文配置。为空时门禁关闭。登录尝试以 Redis 支持的节流限制为每个来源每分钟 5 次；多人共享出口可能共同受到限制。

`GET /api/bootstrap` 在未解锁时只返回 access_required 和 CSRF token。`POST /api/access/unlock` 接收 password，成功后旋转 Session ID/CSRF token；`POST /api/access/lock` 锁定门禁但不混淆或删除当前工作区。`GET /api/datasets` 列出当前浏览器仍在保留期内的已导入数据集。源检查和转换任务返回 dataset_available、dataset_expires_at、input_dataset_id。

Health 仍是公开的简要依赖状态接口；内部监控不可从公网访问。前端静态代码可下载，但所有工作区数据 API 均在后端强制检查门禁，而非只隐藏按钮。

## 验证边界

自动化测试会用合成 S3 协议环境验证“导入后过期仍能处理”，以及原对象在测试环境中移除后快照不变；模拟来源不会被记录为真实 AWS 证据。当前项目尚未发现用户所述的 contacts.csv/contacts.xlsx 或其真实 AWS 连接资料，不宣称这些文件已经在本项目成功访问。真实 S3 仍需使用合法授权的 AWS 凭据进行独立验收。
